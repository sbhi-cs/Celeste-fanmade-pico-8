# Celeste but not!
This is my remake of Celeste (the PICO-8 version)
Celeste is one of my favorite games, and being able to make my own remake of it is so cool!

## Controls
Movement: 
* Left and Right arrow keys (or A and D) to move l/r
* Spacebar/X to jump
    * You can control jump height by holding jump for less or more time
* Z to dash
    * Hold arrow key/WASD of which direction you want to dash in when dashing
    * Diagonal dashes are allowed

UI: 
* CTRL+M to go back to menu from main screen
