# Celeste but not!
This is my remake of Celeste (the PICO-8 version)

Celeste is one of my favorite games, and being able to make my own remake of it is so cool!

## How to download
* Go to the release link: <https://github.com/sbhi-cs/Celeste-fanmade-pico-8/releases/tag/V2.0.0>
* Donwload the .zip file based on your OS
* No support for mac, sorry..

## Controls
Movement: 
* Left and Right arrow keys (or A and D) to move l/r
* Spacebar/X to jump
    * You can control jump height by holding jump for less or more time
* Z to dash
    * Hold arrow key/WASD of which direction you want to dash in when dashing
    * Diagonal dashes are allowed

UI: 
* CTRL+M to go back to menu from main screen

## More about the game
* Currently, this game has 10 levels, across 2 Worlds (each world has its own theme)
* It has a sandbox mode if you just want to mess around with the physics
* It's super fun :D
